WHAT THIS BUILD INCLUDES
- 21 static HTML pages with responsive design.
- Professional colourful UI: blue, violet, cyan, pink, amber and green accents.
- Original monochrome TWA logo retained for brand identity.
- System-font stack only: no external font download, no render-blocking font request.
- Minified production CSS: assets/styles.min.css
- Readable CSS source: assets/styles.css
- Minified JavaScript: assets/script.min.js
- Unique page titles, meta descriptions, canonicals and Open Graph metadata.
- Organization / WebSite / Service / Breadcrumb / Article JSON-LD where applicable.
- sitemap.xml and robots.txt.
- HTTPS + www canonical redirects in .htaccess.
- Brotli/GZIP compression support, browser caching and security headers in .htaccess.
- Accessible headings, focus states, skip link, mobile navigation and responsive layouts.

DEPLOYMENT
1. Back up the current public_html folder.
2. Upload the CONTENTS of this folder to public_html (not the outer folder itself).
3. Confirm that index.html is directly inside public_html.
4. Visit https://www.thewritingagencyindia.in/ and hard-refresh once (Ctrl+F5).
5. Test Home, Services, one service page, one blog article and Contact on mobile and desktop.
6. In Google Search Console submit: https://www.thewritingagencyindia.in/sitemap.xml
7. Inspect the homepage and key service pages with URL Inspection and request indexing.
8. Test deployed URLs with Google Rich Results Test and PageSpeed Insights.

IMPORTANT
- SEO improvements support crawlability, relevance and usability; no code can guarantee a ranking position.
- Keep claims, testimonials, prices and credentials factual and verifiable.
- Publish genuinely useful new resources over time and update older articles when needed.
- If your hosting is Nginx rather than Apache, .htaccess rules will not apply; copy equivalent rules into Nginx configuration.
